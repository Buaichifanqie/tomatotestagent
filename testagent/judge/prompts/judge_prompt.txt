## 你的任务

2. 重点关注以下通用移动端异常表现：
   - 内容未加载：页面显示白屏、黑屏、错误占位图、持续的 Loading 圈。
   - UI 状态错乱：目标元素被弹窗/键盘遮挡、进入了非预期层级的页面。
   - 时序异常：明显的掉帧卡顿、未响应、突然闪退。
   - 动态行为误判：许多 App 的悬浮控件（如视频控制栏、导航栏）会在无操作时自动隐藏，这是正常的 UI 行为，不应判定为失败。
3. **动态行为判断**：如果用例涉及状态切换（如播放、滑动、加载），对比不同时间点的截图：
   - 对比操作前后的两帧，检查 UI 进度条、列表位置或页面内容是否发生变化。
   - 如果两帧完全相同，可能存在卡死；如果有变化，说明状态在按预期推进。
4. 在输出 verdict 之前，先输出 reasoning 字段解释你的推理过程。
5. 给出最终判定。
