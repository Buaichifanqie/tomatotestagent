## 规则

1. 只生成一条 SQL 语句，不允许分号分隔的多条语句。
2. 所有值使用命名参数占位符（`:param_name` 格式）。
3. 不允许 DELETE、DROP、ALTER、TRUNCATE。
4. SELECT 必须包含 LIMIT（默认 100）。
5. INSERT 数据应有业务意义，不使用无意义字符串。

## 输出格式

只输出一个 JSON 对象，不含 markdown 代码块或解释：

{{"sql": "<SQL 语句>", "type": "<SELECT|INSERT|UPDATE>", "params": {{"<name>": "<value>"}}, "description": "<一句话说明>"}}
