# 哔哩哔哩搜索功能测试

B 站搜索功能的完整交互测试，覆盖搜索入口、输入、结果展示、历史记录和边界情况。

## 硬性约束

1. **搜索历史会持久存在**。上一个 TC 搜索的关键词会进入搜索历史。测试"搜索历史为空"等场景时，必须在前置条件中先清除搜索历史（`exec: clear_app_data`）。**不能假设搜索历史为空**。
2. **空搜索 = 不输入任何文字直接按搜索/回车**。测试空搜索时，步骤中不能有 type 操作。点了搜索框之后直接按 KEYCODE_ENTER 或点击搜索按钮，不输入任何文本。
3. **搜索历史弹窗可能在点击搜索栏时弹出**。需要先关闭弹窗（点击右上角关闭）再继续操作。
4. **断网搜索测试需要清除缓存**。B 站有搜索结果缓存，只关网络不够。断网后必须清除缓存再冷启动，具体步骤见 SKILL.md 的断网测试注意事项。断网时搜索页面显示「网络异常，请稍后重试」，target 应使用 `网络异常请稍后重试`。

## When to Use

- 测试搜索入口（首页顶部搜索栏）
- 测试关键词搜索和结果展示
- 测试搜索历史记录
- 测试搜索建议/联想
- 测试边界情况（空搜索、超长输入、特殊字符）

## 视觉特征库

### 搜索入口
- **顶部搜索栏**：首页顶部，灰色背景圆角矩形，右侧放大镜图标
- 点击后进入搜索页

### 搜索页
- **搜索框**：顶部白色输入框，内有灰色 placeholder「搜索」，自动获焦弹出键盘
- **搜索历史**：输入框下方展示历史搜索词标签（圆角灰色标签）
- **搜索建议**：输入时下方实时出现建议列表
- **搜索结果**：视频卡片列表，左侧封面图 + 右侧标题/UP主/播放量

## 核心交互模式

### 1. 搜索流程

```json
{"action": "launch", "target": "${app_package}"}
{"action": "tap", "target": "顶部搜索框"}
{"action": "type", "target": "搜索输入框", "value": "关键词"}
{"action": "tap", "target": "键盘搜索按钮"}
{"action": "wait", "target": "搜索结果加载"}
```

### 2. 从搜索结果进入视频

```json
{"action": "tap", "target": "第一个视频结果"}
{"action": "wait", "target": "视频加载"}
```

### 3. 返回搜索页

```json
{"action": "tap", "target": "返回按钮"}
```

## 边界情况

| 场景 | 预期行为 |
|------|---------|
| 空搜索 | 点击搜索按钮应无响应或提示 |
| 超长输入（256+ 字符） | 应截断到最大长度 |
| 特殊字符（emoji、HTML 标签） | 应正常处理，不崩溃 |
| 无结果关键词 | 显示「暂无结果」或类似提示 |
| 弱网/断网 | 显示"网络不给力"超时提示 |

## 搜索历史操作

**⚠️ 搜索历史是持久存储的**——上一步搜索的关键词会自动进入历史。设计多步骤的场景时请注意：

- 测试"搜索历史为空"需要在开始前清除应用数据：前置条件写 `exec: clear_app_data` 或 `state:clear_search_history`
- 测试"搜索历史显示关键词"应在 TC 内先搜索一次，再验证历史中出现
- 搜索历史的前置 TC 不要排序在前面，如果必须排序，需在 TC 前置条件中做清除

## Tips

- 搜索历史弹窗会遮挡搜索框，需先关闭
- 软键盘弹出后搜索按钮可能被遮挡，可用 KEYCODE_ENTER 替代点击搜索按钮
- 弱网下搜索会超时，需要等待加载完成
- 搜索结果页可以滑动加载更多
- 空搜索的正确步骤是：点击搜索框 → KEYCODE_ENTER（不 type）
