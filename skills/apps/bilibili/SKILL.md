# 哔哩哔哩 App 测试技能

哔哩哔哩（B站）移动端 App 的自动化测试技能，提供视觉特征识别、UI 交互模式和已知陷阱的完整知识。

> **target 名称基于 B 站 v9.0.0，升级后需复核。** 底层优先使用 `resource_id` / `accessibility_id` 定位，中文 target 名作为可读别名。

## 子技能

| 子技能 | 文件 | 触发关键词 | 说明 |
|--------|------|-----------|------|
| 视频播放 | `video_playback.md` | 视频、播放、全屏、倍速、弹幕 | 播放器控制、全屏、清晰度、倍速、弹幕开关 |
| 搜索功能 | `search_flow.md` | 搜索、search | 搜索入口、输入、结果、边界情况 |

## When to Use

- 测试哔哩哔哩 App 的视频播放功能
- 测试哔哩哔哩 App 的搜索功能
- 测试哔哩哔哩 App 的弹幕、评论、互动功能
- 需要识别 B 站特有 UI 元素（控制栏、弹幕开关、全屏按钮、竖屏按钮等）

## 登录状态管理

**默认状态：已登录。** 项目框架默认 App 是已登录状态。

### 如何检查登录状态

**统一判断依据**：点击「我的」，检查页面顶部是否显示用户头像 + 昵称 + 等级。
- **已登录**："我的"页顶部有用户头像、昵称（如"用户1234"）、等级标识、关注/粉丝数
- **未登录**："我的"页显示手机号输入框、验证登录按钮、或"登录即可体验完整功能"提示

> ❌ 不要用底部导航栏判断登录状态——未登录时底部 5 个 Tab 也都可见。

### 登录流程

自动化登录的难点在于短信验证码无法被框架自动读取。按优先级降序排列：

**优先方案：直接注入登录态（推荐）**
```json
// 将预设账号的 token/cookie 写入 App 数据目录
// 路径：data/data/tv.danmaku.bili/shared_prefs/
// 需要预先从手动登录的设备导出登录态文件
{"action": "exec", "value": "adb push local_login_data.xml /data/data/tv.danmaku.bili/shared_prefs/"}
{"action": "exec", "value": "adb shell am force-stop tv.danmaku.bili"}
{"action": "launch", "target": "${app_package}"}
```

**次选方案：扫码登录**
```json
// 生成登录二维码，用测试设备扫码
// 需要 PC 端或另一台设备配合
```

**兜底方案：手机号 + 短信验证码**
```json
{"action": "launch", "target": "${app_package}"}
// 如果不在首页，先恢复首页
{"action": "tap", "target": "底部导航我的"}
// 如果已登录，跳到断言步骤
{"action": "type", "target": "手机号输入框", "value": "${phone_number}"}
{"action": "tap", "target": "验证登录按钮"}
// 等待短信——需配合验证码读取服务（监听短信广播 / adb logcat 抓取）
{"action": "wait", "target": "短信验证码输入框"}
{"action": "type", "target": "短信验证码输入框", "value": "${sms_code}"}
{"action": "wait", "target": "登录完成"}
```

**登录后必须有显式断言**，失败则告警并跳过依赖登录的 TC：

```json
// 登录成功的断言
{"action": "tap", "target": "底部导航我的"}
{"action": "assert", "target": "用户头像可见"}
{"action": "assert", "target": "用户昵称可见"}
```

### 未登录测试用例的状态切换

**测试"未登录"场景时**，按以下流程操作：

1. 前置条件中写 `state:logged_out` 触发退出登录
2. 执行退出登录操作（见下方退出登录流程）
3. 执行未登录的测试步骤
4. 测试完成后**恢复登录状态**：执行登录流程

### 退出登录流程

**首选：UI 路径退出（推荐）**——只清除登录态，不影响其他数据：

```json
// 精确路径：我的 → 右上角齿轮「设置」→ 滑到底部「退出登录」→ 弹窗点「确定」
{"action": "tap", "target": "底部导航我的"}
{"action": "tap", "target": "设置按钮（右上角齿轮图标）"}
// 滑动到页面底部
{"action": "swipe", "target": "设置页面", "value": "swipe_up"}
{"action": "tap", "target": "退出登录"}
// 确认弹窗
{"action": "tap", "target": "确定按钮"}
```

**降级方案：`adb shell pm clear`**——⚠️ 清的是**应用全部数据**，不只是登录态。会连带清掉：
- 首次启动标记（新手引导弹窗会再次弹出，干扰后续 TC）
- 播放/画质/夜间模式等设置
- 离线缓存视频
- 推荐算法冷启动（首页推荐退回冷启动状态）

```json
// 仅当「完全冷启动 + 未登录」双条件同时需要时使用
{"action": "exec", "value": "adb shell pm clear tv.danmaku.bili"}
```

## 视觉特征库

### 首页

#### 底部导航栏

国内版底部导航栏 5 个 Tab，从左到右：

| Tab | target 名称 | 说明 |
|-----|-----------|------|
| 首页 | `底部导航首页` | 推荐流首页，始终可见 |
| 关注 | `底部导航关注` | 关注 UP 主动态页（原「动态」Tab，2023 年改名）。登录后可用；未登录点击提示登录 |
| + | `底部导航发布` | 发布作品。登录后可用；未登录点击提示登录 |
| 会员购 | `底部导航会员购` | 商城页面。**浏览商品/商品详情不需登录**，下单/加购物车/领券需要登录 |
| 我的 | `底部导航我的` | 个人中心。登录后显示头像/昵称/等级/关注数/粉丝数；未登录显示手机号登录入口 |

**⚠️ B 站的动态页面就是「关注」Tab，不是「动态」。target 名称统一用 `底部导航关注`。**

- **顶部搜索栏**：右侧有放大镜图标，灰色背景圆角矩形
- **推荐流**：上下滑动的视频卡片列表，每个卡片包含封面图 + 标题 + 播放量

### 搜索页
- **搜索框**：顶部白色输入框，内有灰色 placeholder「搜索」
- **搜索历史**：输入框下方展示历史搜索词标签（圆角灰色标签）
- **搜索建议**：输入时下方实时出现建议列表
- **搜索结果**：视频卡片列表，左侧封面图 + 右侧标题/UP主/播放量

### 播放页
- **视频区域**：占据屏幕上半部分，竖屏模式
- **UP 主信息**：视频下方显示头像 + 昵称 + 关注按钮
- **互动区**：右侧竖排「点赞」「投币」「收藏」「分享」图标
- **推荐列表**：下方相关视频卡片列表
- **控制栏（默认隐藏）**：点击视频区域后浮现，3~5 秒后自动消失
  - 底部：进度条 + 播放/暂停按钮 + 全屏按钮（最右侧）+ 竖屏
  - 顶部：返回按钮 + 视频标题
- **弹幕层**：视频上方滚动的文字流（可关闭）

### 会员购

会员购是 B 站的 IP 衍生品电商平台（非大会员订阅服务），底部导航栏第 4 个 Tab。

**页面结构：**
- **顶部搜索栏**：搜索商品名称
- **分类 Tab 栏**：手办、周边、雕像、一番赏、魔力赏、盲盒、票务等横向分类
- **商品推荐流**：上下滑动的商品卡片列表，每个卡片包含商品图 + 标题 + 价格 + 标签（如「预售」「现货」「热卖」）
- **商品详情页**：商品大图 + 价格/定金 + 发货时间 + 商品描述 + 规格选择 + 购买按钮
- **购物车**：右上角购物车图标，点击进入购物车列表

**关键交互：**
- **未登录状态下**：可以浏览商品列表和商品详情，但下单/加购物车需要登录
- **已登录状态下**：可以加购物车、下单购买、查看订单
- **购买流程**：选择商品 → 点击「立即购买」或「加入购物车」→ 确认地址 → 提交订单 → 支付（60 秒内完成）
- **预售商品**：先付定金，到货后补尾款
- **优惠方式**：优惠券、红包、魔晶抵扣

**target 名称：**

| 元素 | target 名称 | 说明 |
|------|-----------|------|
| 会员购入口 | `底部导航会员购` | 底部导航栏第 4 个 Tab |
| 商品搜索框 | `会员购搜索框` | 顶部搜索商品 |
| 商品卡片 | `商品卡片` | 推荐流中的商品 |
| 分类 Tab 栏 | `会员购分类Tab` | 手办/周边/雕像等 |
| 搜索按钮 | `会员购搜索按钮` | 搜索执行按钮 |
| 立即购买 | `立即购买按钮` | 商品详情页购买 |
| 加入购物车 | `加入购物车按钮` | 商品详情页加购 |
| 购物车图标 | `购物车图标` | 页面右上角 |
| 返回按钮 | `返回按钮` | 页面左上角返回 |

**断网时**：显示「网络不给力」或商品列表空白。

## 断网测试注意事项

### 问题说明

**B 站有页面和视频缓存。** 单纯断开网络，首页推荐流、搜索结果、已加载的视频仍可正常显示：

| 缓存类型 | 位置 | force-stop 后 |
|---------|------|--------------|
| 首页推荐快照 | 内存 + 磁盘 | 磁盘缓存仍存在 |
| 封面图 CDN 缓存 | 本地磁盘 | 不清除 |
| 视频分段缓存 | 本地文件 | 不清除 |

`adb shell am force-stop` **只杀进程，不清磁盘缓存**。依赖 force-stop 次数来清缓存不可靠（不同版本缓存策略不同）。

### 标准操作流程

```json
// 断网测试的前置条件
// 步骤 1：断网
{"action": "exec", "value": "adb shell svc wifi disable && adb shell svc data disable"}
// 步骤 2：等待网络状态稳定（模拟器虚拟网络栈有时延迟更新）
{"action": "wait", "value": "5000"}
// 步骤 3：清除缓存（选择一种方式）
// 方式 A：使用 App 内置清缓存路径（推荐，不清登录态）
// 我的 → 离线缓存 → 设置 → 清理本地缓存
// 方式 B：pm clear（清全部数据，会连带清登录态和其他设置，慎用）
// {"action": "exec", "value": "adb shell pm clear tv.danmaku.bili"}
// 步骤 4：冷启动
{"action": "exec", "value": "adb shell am force-stop tv.danmaku.bili"}
{"action": "launch", "target": "${app_package}"}
// 步骤 5：等待 App 检测到网络变化（10 秒，模拟器需更长时间）
{"action": "wait", "value": "10000"}
// 步骤 6：下拉刷新主动触发网络请求（可选，更可靠）
// 执行测试步骤，断言网络异常提示
```

**测试完成后恢复网络：**
```json
{"action": "exec", "value": "adb shell svc wifi enable && adb shell svc data enable"}
```

### 各页面网络异常提示文案

断网断言时，不同页面的异常文案不同，target 必须匹配实际页面：

| 页面 | 实际文案/特征 | target 建议 |
|------|-------------|------------|
| 首页推荐流 | 空白骨架屏，或「加载失败，点击重试」按钮 | `加载失败点击重试` |
| 搜索结果 | 「网络异常，请稍后重试」 | `网络异常请稍后重试` |
| 视频播放 | 黑屏，或「加载失败」文字，或「网络连接失败，点击重试」 | `加载失败` |
| 直播间 | 连接断开提示，或直播画面冻结 | `连接断开` |
| 动态/关注 | 加载动画不停止，空白内容 | `加载中` 或空白内容 |
| 会员购 | 商品列表空白，或「网络不给力」 | `网络不给力` |
| 专栏 | 一直显示加载动画，无内容 | `加载中` |

## 已知陷阱

- **搜索历史弹窗**会遮挡搜索框（需先关闭）
- **软键盘弹出**后搜索按钮可能被遮挡
- **弱网下搜索**会超时并显示"网络不给力"
- **控制栏默认隐藏**：播放页看不到播放/暂停/全屏按钮/竖屏，必须先点击视频区域
- **控制栏自动消失**：浮现后几秒无操作即隐藏，操作需在浮现期间完成
- **竖屏不在首页**：必须先进入播放页再触发控制栏
- **互动区不在首页**：点赞、投币、收藏、分享按钮在视频播放页右侧，首页推荐流没有这些按钮
- **首页底部 Tab 容易误点**：底部导航栏与页面内容区接近，坐标定位时注意区分
- **弹幕输入框容易误触**：视频播放页底部有弹幕输入框（placeholder「发个友善的弹幕见证当下」），点击「更多按钮」或控制栏底部区域时可能意外触发键盘弹出。键盘弹出后会遮挡视频控制栏，导致后续操作（如倍速切换、清晰度切换）失败。**解决方案**：在操作「更多菜单」前，先用 `exec` 命令检查键盘状态：`adb shell dumpsys input_method | grep mInputShown`，如果键盘已弹出，先按返回键收起键盘再继续操作

## Tips

- B 站的视频播放控制栏是隐藏的，所有控制栏操作都需要先 `tap_first` 唤出控制栏
- 弹幕开关是常驻显示的，不需要 tap_first
- 双击视频区域可以快速暂停/恢复播放，比通过控制栏更可靠
- 全屏模式下屏幕方向变为横屏，所有坐标系都会变化
- 清晰度切换必须在全屏模式下才能操作

## 启动后页面恢复

B 站有状态恢复机制，force-stop 后冷启动可能恢复到上次的页面（视频详情页、游戏页等），而不是首页。

### 首页视觉特征

首页有以下特征，可用于判断是否在首页：
- **顶部搜索栏**：灰色背景圆角矩形，内有放大镜图标
- **底部导航栏**：5 个 Tab（首页、关注、+、会员购、我的），首页 Tab 为粉色选中态
- **推荐视频流**：上下滑动的视频卡片列表，每个卡片有封面图 + 标题 + 播放量
- **分类标签**：搜索栏下方有「直播」「推荐」「热门」等横向标签

### 非首页特征（需要恢复）

以下特征说明不在首页，需要恢复：
- **视频播放页**：有视频播放区域、UP 主信息、互动按钮（点赞/投币/收藏/分享）、弹幕层
- **游戏/应用详情页**：有「预约」「下载」按钮、应用评分、应用介绍
- **直播间**：有直播画面、礼物栏、弹幕流
- **搜索结果页**：有搜索框 + 搜索结果列表
- **登录页**：有手机号输入框、验证登录按钮

### 恢复策略

1. **优先**：点击底部导航栏的「首页」Tab（最可靠，一次点击直达首页）
2. **备选**：按返回键（可能需要多次，且可能触发「再按一次退出」）
3. **兜底**：force-stop + 重新启动（最后手段，会丢失当前状态）
