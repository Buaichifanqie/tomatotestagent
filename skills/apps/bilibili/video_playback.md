## 视觉特征库

### 播放页
- **视频区域**：占据屏幕上半部分，竖屏视频占中部区域
- **UP 主信息**：视频下方显示头像 + 昵称 + 关注按钮
- **视频标题**：UP 主信息下方，单行或多行
- **互动区**：右侧竖排「点赞」「投币」「收藏」「分享」图标
- **推荐列表**：互动区下方，相关视频卡片列表
- **底部评论区**：可展开的评论入口

### 控制栏（隐藏状态，默认不可见）
- **浮现方式**：点击视频区域后浮现，3~5 秒无操作后自动隐藏
- **顶部**：返回按钮（左）、视频标题（中）、更多按钮（右）
- **底部**：进度条（可拖动）、当前时间 / 总时长、播放/暂停按钮、竖屏（最右侧）
- **竖屏**：控制栏最右侧，图标为「展开」样式（四个角向外的箭头），文字标签为「竖屏」

### 全屏模式
- **横屏**：视频铺满全屏，控制栏在底部
- **退出全屏**：点击视频区域浮现控制栏，点击竖屏（图标变为「收缩」）或按返回键
- **清晰度切换**：全屏模式下，点击视频区域唤出控制栏，控制栏上显示当前清晰度（默认「自动」），点击可切换

## 核心业务流

### 1. 从首页进入视频播放页
1. 在首页推荐流中，点击任意一个视频卡片
2. 页面跳转到视频播放页（竖屏模式）
3. 视频自动开始播放

### 2. 显示/隐藏控制栏（复合动作）

控制栏默认隐藏，浮现后 3~5 秒自动消失。**操作控制栏按钮时必须使用 `tap_first` 复合动作**：

```json
{"action": "tap", "target": "暂停按钮", "tap_first": "播放器画面"}
{"action": "tap", "target": "竖屏", "tap_first": "播放器画面"}
{"action": "tap", "target": "进度条", "tap_first": "播放器画面", "value": "50%"}
{"action": "tap", "target": "更多按钮", "tap_first": "播放器画面"}
```

- **显示**：点击视频区域任意位置 → 控制栏浮现（顶部标题栏 + 底部进度条 + 播放/暂停 + 竖屏）
- **隐藏**：3~5 秒无操作后控制栏自动消失
- **重要**：控制栏是**隐藏**的，不点击视频区域就看不到播放按钮和竖屏

### 2b. 暂停/恢复播放（快捷方式）

不需要唤出控制栏，直接在视频区域操作：

```json
{"action": "double_tap", "target": "播放器画面"}
```

- **暂停**：在视频播放状态下，快速双击视频区域 → 视频暂停
- **恢复播放**：在视频暂停状态下，再次快速双击视频区域 → 视频恢复播放
- **优势**：比 tap_first + 点击暂停按钮更简单可靠，不需要等待控制栏浮现

### 3. 全屏操作
**进入全屏：**
1. 在播放页，点击视频区域 → 控制栏浮现
2. 点击控制栏最右侧的竖屏
3. 视频切换为横屏全屏模式

**退出全屏：**
1. 在全屏模式下，点击视频区域 → 控制栏浮现
2. 点击控制栏最右侧的竖屏（此时图标为「收缩」）
3. 视频恢复竖屏播放页

### 4. 倍速播放

倍速设置在控制栏右上角的「更多」菜单（三点图标）中，需要 tap_first 唤出控制栏后再点击：

```json
{"action": "tap", "target": "更多按钮", "tap_first": "播放器画面"}
```

进入「更多」菜单后，可以看到倍速选项：

```json
{"action": "tap", "target": "2.0x"}
```

- **更多按钮**：控制栏顶部右侧，三个点图标，点击后弹出设置菜单
- **倍速选项**：菜单中显示可用倍速（如 0.5x/0.75x/1.0x/1.25x/1.5x/2.0x），点击切换

### 5. 清晰度切换

清晰度切换**必须在全屏模式下**才能操作，流程如下：

1. 先进入全屏模式：

```json
{"action": "tap", "target": "竖屏", "tap_first": "播放器画面"}
```

2. 进入全屏后，点击视频区域唤出全屏控制栏：

```json
{"action": "tap", "target": "自动", "tap_first": "播放器画面"}
```

3. 点击「自动」后弹出清晰度选项菜单：

```json
{"action": "tap", "target": "720P"}
```

- **自动**：全屏控制栏上显示当前清晰度（默认为「自动」），点击后展开清晰度选项列表
- **清晰度选项**：自动 / 360P / 480P / 720P / 1080P 等，点击切换
- **重要**：竖屏模式下没有清晰度切换入口，必须先进入全屏

### 6. 弹幕开关
弹幕开关是常驻显示的，不需要唤出控制栏，直接点击即可：

```json
{"action": "tap", "target": "弹幕开关"}
```

- 弹幕图标（气泡样式）在视频播放区域右侧，始终可见
- 点击后弹幕开启/关闭切换

### 6. 快进/快退（快捷方式）

不需要唤出控制栏，直接在视频区域滑动：

```json
{"action": "swipe", "target": "播放器画面", "value": "left"}
{"action": "swipe", "target": "播放器画面", "value": "right"}
```

- **快进**：在视频播放区域向左滑动 → 视频快进
- **快退**：在视频播放区域向右滑动 → 视频快退
- **优势**：比 tap_first + 拖动进度条更简单可靠，不需要等待控制栏浮现和计算进度条坐标

### 6b. 进度条拖动（精确控制，备用方式）

如果需要精确跳转到指定位置，仍可通过控制栏的进度条操作：

1. 先 tap_first 唤醒控制栏（点击视频区域中心）
2. vision 获取进度条上当前播放位置的坐标 (x, y)
3. 计算拖动目标：前进 → (x + offset, y)，后退 → (x - offset, y)
4. 执行 swipe 从 (x, y) 到目标坐标

```json
{"action": "swipe", "target": "进度条", "tap_first": "播放器画面", "value": "forward_10s"}
```

### 控制栏交互的关键知识

| 知识项 | 值 | 说明 |
|--------|-----|------|
| 触发区域 | 屏幕中心 (screen_w//2, screen_h//2) | 点击视频区域任意位置均可唤醒控制栏 |
| 浮现等待 | 0.8~1.0 秒 | 点击后需等待控制栏完全浮现再截图 |
| 消失时间 | 3~5 秒 | 无操作后控制栏自动隐藏 |
| 暂停按钮 | 控制栏底部中间偏左 | 播放时显示为「暂停」图标，暂停时显示为「播放」图标 |
| 竖屏 | 控制栏最右侧 | 图标为四角展开箭头，文字为「竖屏」 |
| 更多按钮 | 控制栏顶部右侧 | 三个点图标，点击后弹出倍速等设置菜单，需要 tap_first |
| 自动 | 全屏控制栏上 | 显示当前清晰度（默认「自动」），点击展开清晰度选项列表，仅在全屏模式下可见 |
| 进度条 | 控制栏底部，横跨视频宽度 | 可拖动，左端=起始，右端=结尾 |
| 弹幕开关 | 视频播放区域右侧，常驻显示 | 气泡样式图标，开启时带红色对勾，关闭时带斜线，不需要 tap_first |
| 双击暂停 | 视频区域任意位置 | 快速双击暂停/恢复播放，不需要唤出控制栏 |
| 滑动快进/快退 | 视频区域任意位置 | 左滑快进，右滑快退，不需要唤出控制栏 |

## 已知陷阱

- **控制栏隐藏是关键**：首页进入播放页后，视频区域是纯画面，没有可见的播放/暂停/竖屏。必须先 tap 视频区域触发控制栏浮现，才能操作这些按钮
- **控制栏自动消失**：浮现后 3~5 秒无操作自动隐藏，操作需在浮现期间完成
- **vision 截图时机**：必须在控制栏完全浮现后（等待 0.8s+）截图，否则 vision 找不到控件
- **竖屏不在首页**：首页推荐流没有竖屏，必须先进入播放页
- **互动区不在首页**：点赞、投币、收藏、分享按钮在视频播放页右侧，首页没有这些按钮。测试收藏/分享等功能必须先进入播放页
- **竖屏 vs 横屏**：首次进入是竖屏，全屏后变横屏，坐标系完全不同
- **弹幕遮挡**：弹幕开启时文字流会遮挡视频画面，可能影响视觉识别
- **广告视频**：部分推荐位是广告，播放页布局可能略有不同（无互动区）
- **双击 vs 单击**：双击视频区域是暂停/恢复，单击是唤出控制栏。执行时注意区分 action 类型（`double_tap` vs `tap`）
- **滑动方向**：B 站的滑动快进/快退方向可能与直觉相反（左滑=快进，右滑=快退），以实际 App 行为准
