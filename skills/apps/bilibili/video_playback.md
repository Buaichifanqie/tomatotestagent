## 视觉特征库

### 播放页
- **视频区域**：占据屏幕上半部分，竖屏视频占中部区域
- **UP 主信息**：视频下方显示头像 + 昵称 + 关注按钮
- **视频标题**：UP 主信息下方，单行或多行
- **互动区**：右侧竖排「点赞」「投币」「收藏」「分享」图标
- **推荐列表**：互动区下方，相关视频卡片列表
- **底部评论区**：可展开的评论入口

### 控制栏（隐藏状态，默认不可见）
- **浮现方式**：点击视频区域后浮现，3~5 秒无操作后自动隐藏
- **顶部**：返回按钮（左）、视频标题（中）、更多按钮（右）
- **底部**：进度条（可拖动）、当前时间 / 总时长、播放/暂停按钮、全屏按钮（最右侧）
- **全屏按钮**：控制栏最右侧，图标为「展开」样式（四个角向外的箭头）

### 全屏模式
- **横屏**：视频铺满全屏，控制栏在底部
- **退出全屏**：点击视频区域浮现控制栏，点击全屏按钮（图标变为「收缩」）或按返回键

## 核心业务流

### 1. 从首页进入视频播放页
1. 在首页推荐流中，点击任意一个视频卡片
2. 页面跳转到视频播放页（竖屏模式）
3. 视频自动开始播放

### 2. 显示/隐藏控制栏
- **显示**：点击视频区域任意位置 → 控制栏浮现（顶部标题栏 + 底部进度条 + 播放/暂停 + 全屏按钮）
- **隐藏**：3~5 秒无操作后控制栏自动消失
- **重要**：控制栏是**隐藏**的，不点击视频区域就看不到播放按钮和全屏按钮

### 3. 全屏操作
**进入全屏：**
1. 在播放页，点击视频区域 → 控制栏浮现
2. 点击控制栏最右侧的全屏按钮
3. 视频切换为横屏全屏模式

**退出全屏：**
1. 在全屏模式下，点击视频区域 → 控制栏浮现
2. 点击控制栏最右侧的全屏按钮（此时图标为「收缩」）
3. 视频恢复竖屏播放页

### 4. 倍速播放
1. 在播放页，点击视频区域浮现控制栏
2. 点击控制栏上的「倍速」按钮
3. 选择倍速（0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x）

### 5. 弹幕开关
1. 在播放页，点击视频区域浮现控制栏
2. 点击控制栏上的弹幕图标（气泡样式）
3. 弹幕开启/关闭切换

## 已知陷阱

- **控制栏隐藏是关键**：首页进入播放页后，视频区域是纯画面，没有可见的播放/暂停/全屏按钮。必须先 tap 视频区域触发控制栏浮现，才能操作这些按钮
- **控制栏自动消失**：浮现后 3~5 秒无操作自动隐藏，操作需在浮现期间完成
- **全屏按钮不在首页**：首页推荐流没有全屏按钮，必须先进入播放页
- **互动区不在首页**：点赞、投币、收藏、分享按钮在视频播放页右侧，首页没有这些按钮。测试收藏/分享等功能必须先进入播放页
- **竖屏 vs 横屏**：首次进入是竖屏，全屏后变横屏，坐标系完全不同
- **弹幕遮挡**：弹幕开启时文字流会遮挡视频画面，可能影响视觉识别
- **广告视频**：部分推荐位是广告，播放页布局可能略有不同（无互动区）
