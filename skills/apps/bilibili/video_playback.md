# 哔哩哔哩视频播放功能测试

B 站视频播放器的完整交互测试，覆盖播放控制、全屏切换、清晰度/倍速设置、弹幕开关、进度拖动等场景。

## When to Use

- 测试视频自动播放功能
- 测试暂停/恢复播放（控制栏按钮或双击快捷方式）
- 测试全屏/退出全屏切换
- 测试清晰度切换（必须在全屏模式下）
- 测试倍速播放设置
- 测试弹幕开关
- 测试进度条拖动/滑动快进快退

## 视觉特征库

### 播放页
- **视频区域**：占据屏幕上半部分，竖屏视频占中部区域
- **UP 主信息**：视频下方显示头像 + 昵称 + 关注按钮
- **视频标题**：UP 主信息下方，单行或多行
- **互动区**：右侧竖排「点赞」「投币」「收藏」「分享」图标
- **推荐列表**：互动区下方，相关视频卡片列表
- **底部评论区**：可展开的评论入口

### 控制栏（隐藏状态，默认不可见）
- **浮现方式**：点击视频区域后浮现，3~5 秒无操作后自动隐藏
- **顶部**：返回按钮（左）、视频标题（中）、更多按钮（右）
- **底部**：进度条（可拖动）、当前时间 / 总时长、播放/暂停按钮、全屏按钮（最右侧）
- **操作方式**：控制栏是隐藏的，不能直接点击控制栏上的按钮。必须使用 `tap_first` 复合动作——先点击视频区域唤出控制栏，再点击目标按钮。示例：`{"action": "tap", "target": "暂停按钮", "tap_first": "视频区域"}`
- **全屏按钮**：控制栏最右侧，点击进入横屏全屏模式
- **竖屏**：控制栏上的独立按钮，与全屏按钮不同

### 全屏模式
- **横屏**：视频铺满全屏，控制栏在底部
- **退出全屏**：点击视频区域浮现控制栏，点击全屏按钮（图标变为「收缩」）或按返回键

### 元素导航指南（如何到达每个控件）

| 目标元素 | 在哪里 | 怎么到达 |
|---------|--------|---------|
| 暂停/播放按钮 | 控制栏底部 | `tap_first="视频区域"` → 点击暂停按钮 |
| 全屏按钮 | 控制栏最右侧 | `tap_first="视频区域"` → 点击全屏按钮 |
| 更多按钮（三点图标） | 控制栏顶部右侧 | `tap_first="视频区域"` → 点击更多按钮 |
| 倍速选项 | 更多按钮的弹出菜单中 | `tap_first="视频区域"` → 点击更多按钮 → 点击倍速值（如 2.0x） |
| 清晰度选项 | 仅在全屏模式下可见 | 先进入全屏 → `tap_first="视频区域"` → 点击「自动」→ 选择清晰度（如 720P） |
| 弹幕开关 | 视频播放区域右侧，常驻可见 | 直接点击，不需要 tap_first |
| 进度条 | 控制栏底部 | `tap_first="视频区域"` → 拖动进度条 |

## 核心交互模式

### 1. 进入视频播放页

从首页推荐流点击视频卡片即可进入播放页，视频自动开始播放。

```json
{"action": "launch", "target": "${app_package}"}
{"action": "tap", "target": "推荐页第一个视频封面"}
{"action": "wait", "target": "视频加载"}
```

### 2. 暂停/恢复播放

**方式 A：控制栏按钮（需要 tap_first）**

```json
{"action": "tap", "target": "暂停按钮", "tap_first": "播放器画面"}
{"action": "tap", "target": "播放按钮", "tap_first": "播放器画面"}
```

**方式 B：双击快捷方式（推荐，不需要 tap_first）**

```json
{"action": "double_tap", "target": "播放器画面"}
```

### 3. 全屏/退出全屏

```json
{"action": "tap", "target": "全屏按钮", "tap_first": "播放器画面"}
```

退出全屏：再次点击全屏按钮（图标变为「收缩」）或按返回键。

### 4. 倍速播放

倍速设置在控制栏右上角的「更多」菜单（三点图标）中：

```json
{"action": "tap", "target": "更多按钮", "tap_first": "播放器画面"}
{"action": "tap", "target": "2.0x"}
```

可用倍速：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x

### 5. 清晰度切换

**必须在全屏模式下才能操作：**

```json
{"action": "tap", "target": "全屏按钮", "tap_first": "播放器画面"}
{"action": "tap", "target": "自动", "tap_first": "播放器画面"}
{"action": "tap", "target": "720P"}
```

- 「自动」是默认清晰度，点击后展开选项列表
- 竖屏模式下没有清晰度切换入口，必须先进入全屏

### 6. 弹幕开关

弹幕开关常驻显示，不需要 tap_first：

```json
{"action": "tap", "target": "弹幕开关"}
```

### 7. 快进/快退

直接在视频区域滑动，不需要唤出控制栏：

```json
{"action": "swipe", "target": "播放器画面", "value": "left"}
{"action": "swipe", "target": "播放器画面", "value": "right"}
```

### 8. 进度条拖动（精确控制）

需要 tap_first 唤出控制栏后操作进度条：

```json
{"action": "swipe", "target": "进度条", "tap_first": "播放器画面", "value": "forward_10s"}
```

## 控制栏交互速查表

| 元素 | 位置 | 是否需要 tap_first | 说明 |
|------|------|-------------------|------|
| 暂停/播放按钮 | 控制栏底部中间偏左 | 是 | 播放时显示「暂停」，暂停时显示「播放」 |
| 全屏按钮 | 控制栏最右侧 | 是 | 进入/退出全屏模式 |
| 竖屏 | 控制栏上 | 是 | 与全屏按钮不同的独立按钮 |
| 更多按钮 | 控制栏顶部右侧 | 是 | 三个点图标，弹出倍速/清晰度菜单 |
| 自动 | 全屏控制栏上 | 是 | 当前清晰度，仅全屏模式可见 |
| 进度条 | 控制栏底部 | 是 | 可拖动，左端=起始，右端=结尾 |
| 弹幕开关 | 视频播放区域右侧 | **否** | 常驻显示，气泡样式图标 |
| 双击暂停 | 视频区域任意位置 | **否** | double_tap，快捷方式 |
| 滑动快进/快退 | 视频区域任意位置 | **否** | 左滑快进，右滑快退 |

## Tips

- 控制栏是隐藏的，所有控制栏操作都需要先 `tap_first` 唤出
- 弹幕开关和双击暂停是快捷方式，不需要 tap_first
- 全屏模式下屏幕方向变为横屏，坐标系完全变化
- 清晰度切换必须先进入全屏模式
- 控制栏浮现后 3~5 秒自动隐藏，操作需在浮现期间完成
- 双击 vs 单击：双击是暂停/恢复，单击是唤出控制栏
- 滑动方向：左滑=快进，右滑=快退（可能与直觉相反）
- toggle_groups 中的元素共享缓存坐标，但全屏切换后缓存会自动清除
