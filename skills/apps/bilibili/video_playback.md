## 视觉特征库

### 播放页
- **视频区域**：占据屏幕上半部分，竖屏视频占中部区域
- **UP 主信息**：视频下方显示头像 + 昵称 + 关注按钮
- **视频标题**：UP 主信息下方，单行或多行
- **互动区**：右侧竖排「点赞」「投币」「收藏」「分享」图标
- **推荐列表**：互动区下方，相关视频卡片列表
- **底部评论区**：可展开的评论入口

### 控制栏（隐藏状态，默认不可见）
- **浮现方式**：点击视频区域后浮现，3~5 秒无操作后自动隐藏
- **顶部**：返回按钮（左）、视频标题（中）、更多按钮（右）
- **底部**：进度条（可拖动）、当前时间 / 总时长、播放/暂停按钮、全屏按钮（最右侧）
- **全屏按钮**：控制栏最右侧，图标为「展开」样式（四个角向外的箭头）

### 全屏模式
- **横屏**：视频铺满全屏，控制栏在底部
- **退出全屏**：点击视频区域浮现控制栏，点击全屏按钮（图标变为「收缩」）或按返回键

## 核心业务流

### 1. 从首页进入视频播放页
1. 在首页推荐流中，点击任意一个视频卡片
2. 页面跳转到视频播放页（竖屏模式）
3. 视频自动开始播放

### 2. 显示/隐藏控制栏（复合动作）

控制栏默认隐藏，浮现后 3~5 秒自动消失。**必须使用 `tap_first` 复合动作**：

```json
{"action": "tap", "target": "暂停按钮", "tap_first": "播放器画面"}
{"action": "tap", "target": "全屏按钮", "tap_first": "播放器画面"}
{"action": "tap", "target": "进度条", "tap_first": "播放器画面", "value": "50%"}
{"action": "tap", "target": "清晰度选择", "tap_first": "播放器画面"}
```

- **显示**：点击视频区域任意位置 → 控制栏浮现（顶部标题栏 + 底部进度条 + 播放/暂停 + 全屏按钮）
- **隐藏**：3~5 秒无操作后控制栏自动消失
- **重要**：控制栏是**隐藏**的，不点击视频区域就看不到播放按钮和全屏按钮

### 3. 全屏操作
**进入全屏：**
1. 在播放页，点击视频区域 → 控制栏浮现
2. 点击控制栏最右侧的全屏按钮
3. 视频切换为横屏全屏模式

**退出全屏：**
1. 在全屏模式下，点击视频区域 → 控制栏浮现
2. 点击控制栏最右侧的全屏按钮（此时图标为「收缩」）
3. 视频恢复竖屏播放页

### 4. 倍速播放
1. 在播放页，点击视频区域浮现控制栏
2. 点击控制栏上的「倍速」按钮
3. 选择倍速（0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x）

### 5. 弹幕开关
1. 在播放页，点击视频区域浮现控制栏
2. 点击控制栏上的弹幕图标（气泡样式）
3. 弹幕开启/关闭切换

### 6. 进度条拖动（复合动作）

进度条是控制栏底部的长条形 UI 元素。拖动进度条需要 tap_first + swipe 组合：

1. 先 tap_first 唤醒控制栏（点击视频区域中心）
2. vision 获取进度条上当前播放位置的坐标 (x, y)
3. 计算拖动目标：前进 → (x + offset, y)，后退 → (x - offset, y)
4. 执行 swipe 从 (x, y) 到目标坐标

```json
{"action": "swipe", "target": "进度条", "tap_first": "播放器画面", "value": "forward_10s"}
```

**注意**：进度条坐标需要 vision 返回一个点，项目代码再做加减法计算拖动终点。

### 控制栏交互的关键知识

| 知识项 | 值 | 说明 |
|--------|-----|------|
| 触发区域 | 屏幕中心 (screen_w//2, screen_h//2) | 点击视频区域任意位置均可唤醒控制栏 |
| 浮现等待 | 0.8~1.0 秒 | 点击后需等待控制栏完全浮现再截图 |
| 消失时间 | 3~5 秒 | 无操作后控制栏自动隐藏 |
| 暂停按钮 | 控制栏底部中间偏左 | 播放时显示为「暂停」图标，暂停时显示为「播放」图标 |
| 全屏按钮 | 控制栏最右侧 | 图标为四角展开箭头 |
| 进度条 | 控制栏底部，横跨视频宽度 | 可拖动，左端=起始，右端=结尾 |
| 弹幕开关 | 控制栏上，气泡样式图标 | 开启时带红色对勾，关闭时带斜线 |

## 已知陷阱

- **控制栏隐藏是关键**：首页进入播放页后，视频区域是纯画面，没有可见的播放/暂停/全屏按钮。必须先 tap 视频区域触发控制栏浮现，才能操作这些按钮
- **控制栏自动消失**：浮现后 3~5 秒无操作自动隐藏，操作需在浮现期间完成
- **vision 截图时机**：必须在控制栏完全浮现后（等待 0.8s+）截图，否则 vision 找不到控件
- **全屏按钮不在首页**：首页推荐流没有全屏按钮，必须先进入播放页
- **互动区不在首页**：点赞、投币、收藏、分享按钮在视频播放页右侧，首页没有这些按钮。测试收藏/分享等功能必须先进入播放页
- **竖屏 vs 横屏**：首次进入是竖屏，全屏后变横屏，坐标系完全不同
- **弹幕遮挡**：弹幕开启时文字流会遮挡视频画面，可能影响视觉识别
- **广告视频**：部分推荐位是广告，播放页布局可能略有不同（无互动区）
